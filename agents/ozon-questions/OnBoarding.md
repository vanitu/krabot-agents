# Настройка подключения к Ozon Seller API

Чтобы я мог работать с вопросами покупателей вашего магазина на Ozon, мне нужен доступ к Seller API. Ниже пошаговая инструкция, как получить необходимые данные.

> **Предполагаем, что вы уже зарегистрированы в Ozon Seller и приняли оферту.**

---

## Шаг 1: Найдите Client ID

**Client ID** — это ваш числовой идентификатор продавца.

Где найти:
1. Войдите в [личный кабинет Ozon Seller](https://seller.ozon.ru/).
2. Перейдите в **Настройки → Seller API**.
3. Скопируйте значение поля **Client-Id**.

---

## Шаг 2: Сгенерируйте API-ключ

**API Key** — секретный ключ, который даёт мне доступ к вашим данным в Ozon.

> ⚠️ **Не передавайте API-ключ посторонним.** Запросы к API изменяют данные в вашем магазине.

Как получить:
1. В личном кабинете перейдите в **Настройки → Seller API**.
2. Нажмите **Сгенерировать ключ**.
3. Придумайте название для ключа.
4. Выберите уровень доступа. Для работы с вопросами покупателей убедитесь, что у ключа есть права на чтение/управление вопросами.
5. Выберите цель использования: для личного пользования или для внешнего сервиса.
6. Нажмите **Сгенерировать**.
7. Скопируйте ключ и сохраните его в надёжном месте — Ozon показывает его только один раз.

> ⏰ **Срок действия ключа — 6 месяцев.** После истечения срока создайте новый ключ в том же разделе и обновите настройки агента.

---

## Шаг 3: Введите данные в форму ниже

Поля, которые нужно заполнить:

- **Client ID** — числовой идентификатор из раздела Seller API.
- **API Key** — скопированный ключ (отображается скрыто для безопасности).

После заполнения нажмите **Далее**, и я проверю подключение.

---
