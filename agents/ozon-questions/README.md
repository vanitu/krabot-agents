## Как это работает

Просто скажите агенту, что нужно сделать:

**Вы:** *«Обработай вопросы покупателей»*  
**Агент:** Находит неотвеченные вопросы, генерирует ответы и публикует их

**Вы:** *«Пришли последний отчёт»*  
**Агент:** Показывает сводку с количеством обработанных вопросов и примерами ответов

**Вы:** *«Сколько неотвеченных вопросов?»*  
**Агент:** Проверяет статус и сообщает актуальное число
