# Справка по агенту «Ozon Reviews»

Привет! Я — ваш ассистент по работе с отзывами на Ozon. Здесь всё, что нужно знать обо мне.

---

## Как со мной разговаривать

Просто пишите своими словами — не нужно запоминать сложные команды. Я пойму, чего вы хотите.

- «Обработай отзывы» — я запущу полный цикл.
- «Сколько отзывов не обработано?» — я покажу статус.
- «Пришли отчёт» — я вышлю последний отчёт.

---

## Команды в Telegram

| Команда | Что делает |
|---------|------------|
| `/process-reviews` | Запускает обработку отзывов прямо сейчас |
| `/status` | Показывает, сколько необработанных отзывов сейчас |
| `/report` | Присылает последний отчёт в формате Markdown |
| `/help` | Показывает эту справку |

---

## Что я делаю автоматически

1. **Проверяю** новые необработанные отзывы.
2. **Отвечаю** на положительные отзывы (4–5★):
   - Если отзыв без фото — случайным шаблонным спасибо.
   - Если отзыв с фото — шаблонным спасибо с упоминанием фото.
   - Если покупатель уже оставил комментарий — я готовлю персонализированный AI-ответ.
3. **Помечаю** обработанные отзывы статусом `PROCESSED`.
4. **Сохраняю** отчёт в файл и присылаю его вам.

Отзывы с рейтингом ниже 4★ я пока пропускаю — их лучше обработать вручную.

---

## Советы для лучшего результата

- Если хотите изменить стиль ответов — отредактируйте файл `company_rules.md` в настройках агента.
- Добавляйте новые шаблоны в `generic_templates.json` и `photos_templates.json`, если хотите разнообразия.
- Следите за сроком действия API-ключа (6 месяцев).

---

## Если что-то пошло не так

| Проблема | Решение |
|----------|---------|
| Агент не запускается | Проверьте, что `OZON_CLIENT_ID` и `OZON_API_KEY` заполнены |
| Ошибка подключения к API | API-ключ мог истечь. Создайте новый в личном кабинете Ozon Seller → Настройки → Seller API |
| Отзывы не обрабатываются | Убедитесь, что у вас есть подписка «Управление отзывами» или Premium Pro |
| AI-ответы не генерируются | Проверьте, что агент видит файл `data/pending_ai_reviews.json` |
