# Стартовые инструкции

Ты запускаешься впервые. Выполни следующие шаги строго по порядку, прежде чем приступить к обычной работе.

---

## Шаг 1: Проверка конфигурации

Убедись, что установлены следующие переменные окружения:
- `OZON_CLIENT_ID`
- `OZON_API_KEY`

Если хотя бы одна из них отсутствует или пустая, отправь в Telegram сообщение:

> ⚠️ Агент не может запуститься. Отсутствуют необходимые настройки: OZON_CLIENT_ID и/или OZON_API_KEY. Пожалуйста, проверьте настройки или обратитесь в поддержку.

Затем остановись.

---

## Шаг 2: Проверка подключения к Ozon API

Выполни команду:

```bash
python3 workspace/skills/ozon-reviews-api/scripts/ozon_reviews.py count
```

Если команда завершилась с ошибкой или в ответе есть ключ `error`, отправь в Telegram:

> ⚠️ Не удалось подключиться к Ozon API. Проверьте, что Client ID и API Key указаны верно, а ключ не истёк.

Затем остановись.

---

## Шаг 3: Приветственное сообщение

Отправь в Telegram:

> ✅ Агент по работе с отзывами Ozon запущен и готов к работе!
>
> Я буду автоматически обрабатывать новые отзывы: отвечать на положительные (4–5★) шаблонными или AI-генерированными ответами, а также формировать отчёты.
>
> Доступные команды:
> - `/process-reviews` — запустить обработку отзывов вручную
> - `/status` — проверить количество необработанных отзывов
> - `/report` — получить последний отчёт
> - `/help` — справка
>
> Также вы можете попросить меня работать по расписанию. Просто скажите: «Настрой автоматический запуск раз в час».

---

## Шаг 4: Первый запуск обработки

Проверь количество необработанных отзывов из ответа команды `count`.

Если `unprocessed` > 0, запусти:

```bash
python3 workspace/skills/ozon-reviews-workflow/scripts/process_reviews.py
```

После завершения сообщи в Telegram краткий результат:
- Сколько отзывов обработано шаблонами
- Сколько подготовлено для AI-ответов
- Сколько пропущено

Если `unprocessed` == 0, отправь:

> На данный момент необработанных отзывов нет. Я буду следить за поступлением новых.

---

## Шаг 5: Переход в рабочий режим

Начни слушать команды из Telegram и/или ожидай следующего запуска по расписанию.
